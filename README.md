# JavaScript Fundamentals

A structured collection of core JavaScript concepts demonstrated through clean, executable examples. Designed for learners building a solid foundation in modern JavaScript.

## Topics Covered

| File | Concept |
|------|---------|
| `01-variables.js` | Variable declaration (`let`, `const`), primitive data types |
| `02-functions.js` | Function declarations, parameters, return values, arrow functions |
| `03-arrays.js` | Array creation, indexing, `push()`, `pop()`, length |
| `04-objects.js` | Object literals, property access, mutation, dynamic properties |
| `05-loops.js` | `for` loops and iterating over arrays |
| `06-conditionals.js` | `if` / `else if` / `else`, ternary operator |
| `07_string-methods.js` | `trim()`, `toUpperCase()`, `toLowerCase()`, `includes()`, `slice()` |
| `08-array-methods.js` | `map()`, `filter()` |
| `09-scope.js` | Global vs local scope |
| `10-objects-methods.js` | Methods inside objects, `this` keyword |

## Getting Started

### Prerequisites
- Node.js (v14 or higher recommended)

### Run Any Example

```bash
node 01-variables.js
node 02-functions.js
# ... and so on
```

Each file is self-contained and prints output to the console.

## Learning Path

Work through the files in numerical order. Each builds on previous concepts:

1. Start with variables and data types
2. Move to functions and control flow
3. Practice collections (arrays & objects)
4. Explore methods and scope
